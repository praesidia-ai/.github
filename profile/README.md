# Praesidia

**Control what AI agents can actually do.**

Praesidia provides security and governance for AI agents and MCP servers. Apply identity checks, tool permissions and approval policies to actions routed through Praesidia, then inspect the evidence those decisions produce.

## Start with a free resource

- **[MCP security checklist](https://praesidia.ai/blog/mcp-server-security-checklist)** — an editable worksheet for reviewing identity, tool permissions, supply chain and audit coverage.
- **[MCP authorization lab](https://praesidia.ai/blog/mcp-oauth-troubleshooting-401-403)** — reproduce authentication and permission failures locally, with synthetic inputs and 21 self-checks.
- **[Signed audit verification lab](https://praesidia.ai/blog/signed-ai-agent-audit-log-verification-example)** — inspect nine synthetic cases covering changed records, broken chains and missing tails.

No email or signup is required for these downloads. The labs are teaching examples; the authorization lab is not a production MCP server or OAuth implementation, and the audit lab is separate from the production export verifier.
